# ONE WORD

> Change one word. Change the world.

Our hackathon project lives in **[`one-word/`](one-word/)**: a puzzle game where every level is a rule
sentence like `YOU [DIE] ON RED`. Rewrite one word (`hide`, `bounce`, `hibernate`…) and the world obeys.
An AI (Gemini or OpenAI) understands words the built-in dictionary doesn't know.

```bash
cd one-word
npm install
npm run dev      # play at the printed localhost address
npm test         # solver proves every level is solvable
```

See [`one-word/README.md`](one-word/README.md) for levels, the level editor, AI keys and the code layout.

`other-games/` holds earlier prototypes from the hackathon (not part of ONE WORD).
