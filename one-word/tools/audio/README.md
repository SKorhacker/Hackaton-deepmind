# Audio generation

Everything in `public/audio/` is generated by these scripts; nothing is licensed third-party material.

## Music (`gen_music.py` + `process.py`)

`gen_music.py` prompts Lyria 3 Clip through the Gemini API Interactions endpoint (30 s clips), one per
mood, into `raw/`. `process.py` turns each clip into a seamless bed: it cuts a 23 s window, equal-power
crossfades the tail back over the head, loudness-normalises to -19 LUFS and encodes 96 kbps MP3.
The two short cues (`sting-win`, `sting-lose`) are cut from the front of their clip and faded out.

```bash
K=$GOOGLE_AI_STUDIO_API_KEY python3 gen_music.py   # writes raw/*.mp3
python3 process.py                                 # writes public/audio/music-*.mp3 + sting-*.mp3
```

Beds: `menu`, `calm`, `tension`, `mystery`, `hope`. `GameScene.updateMusic()` picks one from the *current*
rule sentence, so rewriting the rule crossfades the score.

## SFX (`gen_sfx.py`)

No model involved: the one-shots are synthesised with numpy (modal resonators for struck wood, filtered
noise for parchment, FM for metal/bells, a tap-delay reverb, then a warmth tilt) and written as 32 kHz
mono WAV. WAV rather than MP3 so there is no decoder priming delay on a cue that must land on the frame.

```bash
python3 gen_sfx.py   # writes public/audio/sfx-*.wav
```

Small, frequent cues (move, bump, bounce, hide, wait) are not sampled at all — they are synthesised live
in `src/ui/Sfx.ts` so they stay free and never repeat identically.
