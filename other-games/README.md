# Other games (earlier prototypes)

Standalone browser games from earlier in the hackathon. They are not part of ONE WORD. Open any file
directly in a browser.

| File | What it is |
|---|---|
| `boss-game.html` | You are the boss; the AI challenger learns to dodge you (NEAT evolution) |
| `bullet-hell.html` | Dodge a boss whose attack patterns adapt to your deaths |
| `platformer.html` | Split-screen platformer; an AI learns from how you die |
| `boss-game-gemini.html` | Boss game with a Gemini strategist panel (reasoning, taunts, predictions) |
| `ai-boss-architect.html` | Gemini designs new bullet patterns aimed at your habits |
| `ai-boss-gamemaster.html` | Gemini rewrites the fight's rules every phase |

The Gemini ones ask for a Gemini API key in their side panel.
